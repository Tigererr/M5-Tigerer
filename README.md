# TIGER OS (M5 Tiger)

**Пилотный проект** кастомной прошивки на MicroPython для устройства **M5StickC Plus 2**. 

Это моя первая версия. Проект будет активно развиваться и дополняться новыми фичами. Если вы заметили баги, нашли ошибку в коде или у вас есть идеи, как сделать лучше — я буду очень рад обратной связи и любым доработкам! Создавайте Issues или присылайте Pull Requests.

## 📋 Что реализовано
*   **Меню**: Удобная навигация с иконками.
*   **Загрузка**: Пиксельный тигр (есть таймер на 2 секунды, можно пропустить кнопкой `A`).
*   **Игры**:
    *   `Тетрис` — с плавным падением и подсчетом очков.
    *   `Акула` — аркада на выживание (управление рыбкой).
    *   `Слоты` — казино 777 (с балансом и анимацией).
*   **Датчики**: Экран с показаниями акселерометра (IMU) в реальном времени (X, Y, Z).
*   **Настройки**: 
    *   Регулировка яркости экрана.
    *   Настройка тайм-аута затухания экрана (или всегда включен).
    *   Отключение/включение заставки с тигром.
    *   Перезагрузка устройства.

## 🛠 Как установить
1. Подключите M5StickC Plus 2 к компьютеру.
2. Используйте UIFlow Web IDE, Thonny или M5Burner.
3. Скопируйте код из файла `M5-Tiger.py`.
4. Сохраните файл на устройстве как `main.py`, чтобы он запускался автоматически при включении.

## 🎮 Управление
*   **Кнопка A** (большая) — Влево / Вверх / Действие / Выбор.
*   **Кнопка B** (маленькая) — Вправо / Вниз.
*   **Кнопка C** (боковая) — Выход в меню / Отмена.
